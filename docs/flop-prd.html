01先把话说清楚

这个项目和翻前训练器有一个本质区别，必须写在第一节，而不是藏在附录里。

翻前只有 169 个起手牌等价类。36 个场景一共 6084 个格子，我能逐格写出来、逐格校验、出一份对照表交你审。那份数据是可以穷举的。

翻牌不行。仅翻牌面就有 22100 种发法，按花色同构归并后仍有 1755 种策略上不同的牌面；每个牌面下双方各有数百个手牌组合，再乘以下注尺度、以及后面两条街的分支，节点数是千万级。这个规模的均衡策略只能由 solver 迭代算出来。

这个 App 不会自称 GTO

按你选的路线，翻牌圈策略来自一套我编写的规则模型，不是 solver 输出。它能教会你正确的思考框架和大方向，在常见牌面上的结论与真实解法高度一致，但在边缘牌面和混合频率的细节上必然有偏差。因此本项目的界面文案、图标名称、文档标题一律不使用「GTO」三个字，只说「训练器」。这不是措辞洁癖，是避免你把一套近似当成真理去背。

好消息是，规则模型有一个 solver 没有的优点：它能解释自己。每一手牌训练完，App 能告诉你「这是 A 高干燥彩虹面，你作为翻前加注者在这类面上有范围优势，所以高频小注」，而 solver 只会给你一个数字。对于打法成型阶段的玩家，可解释性比小数点后两位更值钱。

路线本身是可升级的。第 9 节的数据层按 solver 输出的结构设计，日后你拿到真实数据，替换数据文件即可，界面不用改。

02产品定位

给已经会翻前范围的玩家，一个练翻牌圈第一个决策的工具。

核心价值

  • 把牌面读成类别，而不是三张具体的牌。高手看到 K♠7♦2♣ 想的不是这三张牌，而是「高牌干燥彩虹，我有范围优势」。训练器要做的就是把这个抽象过程变成肌肉记忆。
  • 两个视角都练。作为翻前加注者决定是否持续下注，以及作为防守方面对持续下注决定跟弃加。多数人只练前者，而后者错得更多。
  • 承接翻前。发到你手上的牌不是随机的，而是从翻前训练器里那套范围中抽出来的。你在 BTN 开池范围里会有什么牌，翻牌圈就会拿到什么牌。

明确不做（v1）

  • 转牌与河牌。节点数暴涨，规则模型的误差会逐街累积。
  • 多人底池。三人以上的翻后策略与单挑差异极大，不是加个座位就能覆盖的。
  • 下注尺度自由输入。每个节点只给两档尺度加过牌，见第 3 节。
  • 精确的混合频率。规则模型给的是频率档位，不是解法的精确值。

04牌面分类模型

整个项目的地基。分类必须覆盖全部 22100 种翻牌，且每一类的出现频率都在合理区间。

两个轴

牌面用两个正交的轴描述。结构轴决定谁的范围占优、该用哪一档尺度；花色轴决定听牌有多少，对尺度做修正。拆成两轴而不是一个大类，是为了让策略表停留在可手写的规模。

轴取值判定规则
结构配对面三张里有两张同点数（含三条）
同花面三张同花色，且不配对
连接面不配对、非同花面，三张跨度 ≤ 4（A 可当 1 用）
A 高干燥跨度 ≥ 5，最大张为 A
KQ 高干燥跨度 ≥ 5，最大张为 K 或 Q
JT 高干燥跨度 ≥ 5，最大张为 J 或 T
低干燥跨度 ≥ 5，最大张为 9 或更小
花色彩虹三种花色
双色恰好两张同花色
单色三张同花色

为什么不按同构归并成 1755

1755 是学术上的「策略不同的牌面数」，但训练时你要看到的是真实发牌。按 22100 全量抽样，各类牌面出现的频率就等于真实牌桌上的频率，这与翻前按组合数加权发牌是同一个道理。

05手牌分类模型

拿到牌面后，把英雄的两张底牌归入八类之一。分类逻辑是纯计算，不含主观判断。

#类别判定
1超强牌两对及以上：两对、暗三条、明三条、顺子、同花
2强顶对及以上超对，或顶对且踢脚为 T 以上
3弱顶对顶对且踢脚为 9 及以下
4中对底对击中第二大或第三大的牌面张，或口袋对低于顶张
5强听牌同花听牌加两头顺，或任一听牌加两张超牌
6普通听牌同花听牌，或两头顺听牌
7弱牌有潜力卡顺听牌、两张超牌、后门同花加后门顺
8空气以上都不是

这八类是策略表的行。分类器要处理的边界情况在 M1 用单元测试逐条钉死，例如口袋对正好等于顶张时算三条不算超对、同花听牌同时是卡顺时归入第 5 类而非第 6 类。

06策略表与判定

策略 = 查表 + 修正。表是手写的，修正是程序算的。

数据结构

每个 (底池类型, 视角, 位置) 组合对应一张 7 结构 × 8 手牌类 的表，每格是一个频率三元组。花色轴不进表，改为程序化修正，否则表的规模会乘以三。

{
  "id": "srp.aggressor.ip",
  "pot": "单加注池", "role": "进攻方", "pos": "有位置",
  "actions": ["bet33", "bet75", "check"],
  "table": {
    "A高干燥": {
      "超强牌":      [ 35, 55, 10],
      "强顶对及以上": [ 70, 20, 10],
      "弱顶对":      [ 75,  0, 25],
      "中对底对":    [ 45,  0, 55],
      "强听牌":      [ 30, 60, 10],
      "普通听牌":    [ 55, 20, 25],
      "弱牌有潜力":  [ 60,  0, 40],
      "空气":        [ 45,  0, 55]
    },
    "连接面": { ... }
  }
}

花色修正

双色面与单色面在结构表的基础上按固定规则调整，规则写在代码里并在对照表页面展示：

  • 双色：小注频率下调 15 个点，等量转入大注；听牌类手牌的下注总频率上调 10 个点。
  • 单色：无同花相关牌力的手牌，下注总频率下调 25 个点转入过牌；持有该花色高张的手牌下注频率上调。
  • 彩虹：不修正，即结构表本身。

判定规则

与翻前完全一致，复用同一个函数：所选动作的频率 ≥ 30% 判正确，频率在 1% 到 29% 之间标为「可接受的低频选择」，与硬错误分开显示。阈值同样可在设置里调成严格或宽松。

校验

构建时逐格检查：三个频率之和等于 100；每张表的加权总下注频率落在预期区间内。预期区间按结构写死，例如单加注池有位置的进攻方，在 A 高干燥面的总下注频率应在 65% 到 85% 之间，在低连接双色面应在 40% 到 60% 之间。超出即在对照表页面标红，与翻前的入池率校验是同一套机制。

07场景矩阵

翻前线路决定了双方范围和位置关系。v1 取四条最高频的线路，各两个视角。

#翻前线路底池英雄视角位置
1BTN 开池，BB 跟注单加注池 5.5 BB进攻方 BTN有位置
2BTN 开池，BB 跟注单加注池 5.5 BB防守方 BB无位置
3CO 开池，BB 跟注单加注池 5.5 BB进攻方 CO有位置
4CO 开池，BB 跟注单加注池 5.5 BB防守方 BB无位置
5UTG 开池，BB 跟注单加注池 5.5 BB进攻方 UTG有位置
6UTG 开池，BB 跟注单加注池 5.5 BB防守方 BB无位置
7BB 3bet，BTN 跟注3bet 池 22 BB进攻方 BB无位置
8BB 3bet，BTN 跟注3bet 池 22 BB防守方 BTN有位置

每个场景的英雄手牌从对应的翻前范围里抽取。线路 1 的 BTN 手牌来自翻前数据集的 open.btn 加注范围；线路 2 的 BB 手牌来自 3bet.bb.vs_btn 的跟注部分。翻前那套数据在这里第二次发挥作用，不需要重新整理。

策略表的数量是 4 张：单加注池进攻方、单加注池防守方、3bet 池进攻方、3bet 池防守方。位置关系在 v1 与底池类型绑定，不单独成表。合计 4 × 7 × 8 = 224 个频率三元组需要手写。

08功能规格

界面骨架与翻前训练器一致，你不用重新学怎么用。

直接复用的

  • 训练循环：每局 20 手、按真实频率发牌、考试与教学两种反馈模式、结算页与评级。
  • 错题本：答错入库，连续答对两次移出，支持只练错题。
  • 统计与存储：按场景累计手数与正确率，全部存在本机。
  • 牌桌渲染：自适应尺寸那一套原样搬过来，只是桌面中央多了三张公共牌。
  • 分享图与设置面。

新增的

  • 公共牌区。牌桌中央显示三张翻牌，底池与双方下注额按翻前线路预置。
  • 场景面的预览从范围表换成分类说明。点开场景卡后，先看到这条线路的双方范围概要、该视角下六类结构的总下注频率柱状图，再决定开练。
  • 每手牌的解释。教学模式下，反馈不只给频率，还给一句话理由，例如「K72 彩虹，你的范围里 K 和超对远多于对手，高频小注施压」。
  • 热力图换成 7 × 8 矩阵。横轴是牌面结构，纵轴是手牌类别，格子按你的错误率着色。翻前是 13×13 的手牌网格，翻后是这张矩阵，作用相同：一眼看出弱点在哪。

第一步是把现有 app.js 里的牌桌渲染和通用界面抽成 table.js 与 ui.js。这一步不改任何行为，抽完后翻前应用必须逐项回归到当前状态才算通过。构建仍用现有的 tools/build.sh，只是多跑一条命令。

两个图标还是一个

按当前方案，两个应用各自有 manifest 和图标，可以分别添加到主屏幕，互不干扰。翻前那个的线上地址完全不变，你已经装好的图标不受影响。两边首页互相放一个入口链接，想换着练的时候点一下就过去了。

11风险与待确认

两个真实风险，三个按默认值推进的问题。

风险

  • 规则模型的可信度无法自证。翻前那份范围我能说「这是标准解法整理的」，翻后这份只能说「这是我按公认原则写的」。缓解办法是把每一格的理由写进对照表，让你能逐条判断，而不是只给数字。若你日后拿到 solver 数据，可以用它反过来校准这张表。
  • 八类手牌的粒度可能不够。例如「空气」里既有带阻断牌的 A 高，也有毫无价值的 72，真实策略对二者处理不同。若训练中发现这一类的判定经常反直觉，就需要把它拆细，届时策略表要重写对应行。

按默认值推进

  1. 应用名称。界面标题用「翻牌圈训练器」，不含 GTO 字样，原因见第 1 节。
  2. 下注尺度档位。进攻方两档 33% 与 75%，防守方加注固定 3 倍。档位越多训练越细但表越大，v1 先用两档。
  3. 先做哪个视角。F4 先跑通进攻方四个场景，确认手感后再接防守方，两者共用同一套界面。
